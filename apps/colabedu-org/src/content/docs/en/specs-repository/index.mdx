The **OPS Specifications Repository** contains the YAML files comprising ColabEdu's pedagogical catalog. Following the **Pedagogy as Code** paradigm, every dimension of the learning process—from statutory framework to onscreen interactivity or rubric grading—is expressed in human-readable and AI-executable specifications.

---

## Sovereignty and GitOps Principles

1. **Atomic Versioning:** Every specification resides in semantically versioned Git repositories (`1.0.0`). Any curricular update requires an auditable Pull Request.
2. **Decoupled Definition from Execution:** Rubrics and exams are authored once in YAML and deployed across diverse LMS systems (Canvas, Moodle, Google Classroom) via LTI Advantage v1.3.
3. **Session-Level Immutability:** When a student begins an assignment, the engine compiles an immutable *Snapshot*. No subsequent changes to rubrics or guidelines alter retroactive grades.

## Open Standard vs. Partner Tooling

| Dimension | Open Standard OPS (`colabedu.org`) | Platform & Partners (`colabedu.net`) |
|---|---|---|
| **Definitions & Schemas** | All public YAML schemas (C0, C1, C2, Containers). | Enterprise telemetry and sovereign district data sync schemas. |
| **Official Taxonomies** | LOMLOE (Spain), CDE (California), College Board (AP), IB Diploma. | Proprietary institutional taxonomies for private networks. |
| **Content Generation** | Schema documentation and validation examples. | **Full Content Factory (ACA)**, `ce-cli`, batch pipelines, and `.imscc` / `.mbz` ingestion. |
| **AI Grading & Tutoring** | Open interfaces for evaluation and feedback contracts. | Multi-criteria scoring calibration, bias audits, and anti-cheating engines. |
