## Type Overview

### BLOCK_RUBRIC
Rubrics define evaluation criteria by subject, level and standard.
Use them in the `rubricRef` field of your specs.

**Key patterns:**
- `es.c0.lomloe.*` — Spanish LOMLOE curriculum rubrics
- `global.c0.ap.*` — AP (Advanced Placement) rubrics
- `global.c0.ib.*` — IB rubrics
- `global.c0.whiteboard.stem.math.v1` — STEM whiteboard vision AI rubric *(new)*

### LIBRARY (Exercise Types)
Exercise type libraries define the UI scaffold and base AI evaluation directive.

**Key exercise types:**
- `global.exercise_type.whiteboard.v1` — Digital whiteboard with Gemini Vision evaluation *(new)*
- `core.etype.mixed_quiz.v1` — Mixed quiz (MCQ + fill-blank)
- `core.etype.socratic_tutor.v1` — Socratic tutor chatbot
- `core.etype.split_pane_essay.v1` — Guided essay in split-pane view

### PERSONA
Personas define the AI evaluator personality injected into exercises.

**Available:**
- `gem.curator_lesson` — Interactive lesson curator (LMS packages)
- `gem.curator_c1` — C1 methodology curator (recipes and exercise types)
- `gem.curator_c0` — C0 rubric curator
- `persona.evaluator.motivator` — Motivating evaluator
- `persona.evaluator.socratic` — Socratic evaluator
