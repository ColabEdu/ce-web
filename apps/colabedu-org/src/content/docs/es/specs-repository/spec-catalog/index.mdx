## ¿Cómo usar estos catálogos?

Los IDs canónicos se referencian en los ficheros YAML OAS mediante los campos
`rubricRef`, `personaRef`, `recipeRef` y similares:

```yaml
# En un ejercicio, referenciar un tipo y una rúbrica:
spec:
  exerciseTypeRef: global.exercise_type.whiteboard.v1
  rubricRef: global.c0.whiteboard.stem.math.v1
```

El catálogo se actualiza automáticamente al ejecutar:
```bash
bash ce-cli.sh taxonomy catalog docs
```
